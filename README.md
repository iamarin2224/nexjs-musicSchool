# 🎵 Music School UI — Next.js Frontend Practice

## 📌 Overview

This project is a **frontend-only UI clone of a music school website**, built to learn the **basics of Next.js (App Router)** and explore **modern UI design** using **Aceternity UI** components.

The focus is strictly on **UI development and design experimentation**, not backend functionality.

---

## 🎯 Purpose

- Learn Next.js project structure and routing
- Practice layout and component composition
- Explore and customize Aceternity UI components
- Build visually rich, modern frontend sections

---

## 🖼️ Pages & Sections

- **Home Page**
  - Hero section
  - Featured courses
  - Testimonials
  - Webinars
- **Courses Page**
- **Contact Page**

All pages are built using **Aceternity UI components** and **Tailwind CSS**.

---

## 🎨 Tech Stack

- Next.js (App Router)
- React
- Tailwind CSS
- Aceternity UI

---

## 🚫 Scope Limitations

- Frontend only
- No backend or APIs
- No authentication or database
- No form submission logic

---

## 🧠 Learning Outcome

This project is intended to strengthen understanding of **Next.js fundamentals**, **component-based UI development**, and **modern design practices**.

---

## 📎 Note

This project is for **learning and experimentation purposes only**.
